# 现代分子生物学 · 本地自学网页

朱玉贤《现代分子生物学》第5版 · ch01–ch05 教师课件逐页详解。

第五章-1《原核生物的转录及其调控（一）》含85页PPT、40道选择、10道判断、10道填空、5道简答、2道论述和12个名词解释。

第五章-2《原核生物的转录及其调控（二）》含87页PPT、38道选择、10道判断、10道填空、5道简答、2道论述和12个名词解释。

## 内容

- 概念逐页讲解
- 本页自测 / 模块考题
- **本章单元测试（课后题优先）**
- 详细答案、答题步骤与解析
- 错题本：支持选择/判断/填空/简答/论述/名词解释重做
- 间隔复习、闪卡、模拟测验、术语表、视频微课

## 本地运行

```bash
python3 -m http.server 8000
```

浏览器打开 `http://localhost:8000/`。

学习记录保存在本机浏览器 localStorage，不会上传。
